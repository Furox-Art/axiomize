# Glossary (basic-tier support)

One-sentence definitions. Rule: in basic mode, link or inline-explain any term below the first time it appears.

| Term | Plain meaning |
|------|---------------|
| Archetype | a famous, well-studied pattern of problem that already has ready-made mathematics |
| Assumption | something we take as true to make the model work; each one is a bet |
| Calibration | adjusting model parameters until model output matches observed data |
| Compartmental model | tracking populations by boxes (S→I→R) with flows between them |
| Confidence interval | the range where the true value plausibly sits, given noise |
| Coupling | when changing one part of the system changes another |
| Endogenous parameter | a quantity the model itself computes (an output) |
| Equilibrium | a state where nothing changes anymore unless pushed |
| Erlang-C formula | the standard equation for average waiting time with multiple servers |
| Exogenous parameter | an input given from outside the model |
| Falsifiability | being able to say in advance what observation would prove the model wrong |
| Final size | the fraction of the population that ever got infected before an epidemic ends |
| Fixed point | a state where all rates of change are zero |
| Gillespie algorithm | exact simulation of random event-by-event dynamics |
| Identifiability | whether data could ever pin down a parameter uniquely |
| Jacobian | table of how fast each quantity pushes each other quantity near a point |
| Markov chain | a process where only the current state matters for what happens next |
| Mean-field approximation | replacing everyone's differences by their average (fast, sometimes wrong) |
| Monte Carlo | answering hard probability questions by running thousands of random simulations |
| Nash equilibrium | a set of choices where nobody can gain by unilaterally switching |
| ODE | equation describing how quantities change continuously in time |
| R₀ | average number of new cases one case causes in a fully susceptible population |
| Sensitivity analysis | checking which input changes actually move the answer |
| Shadow price | the value of relaxing a scarce resource by one unit |
| Stability | whether a system returns to equilibrium after small disturbances |
| Stationary distribution | long-run probabilities of being in each state |
| Stochastic | containing randomness as a first-class citizen |
| Utilization (ρ) | fraction of capacity in use; near 1 means queues explode |

Maintenance rule: add a term here the first time a perspective file uses it without definition.
