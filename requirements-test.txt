# z3-solver is declared once, in both this file and pyproject.toml, with the
# same requirement. It used to be declared twice in pyproject.toml, once per
# platform marker ("...; sys_platform == 'darwin'" and
# "...; sys_platform != 'darwin'"), and that broke two things at once.
#
# Dependabot's Python file updater resolves the declaration it is replacing
# against a single unambiguous requirement. Given two entries for the same
# distribution it failed with "Declaration not found for z3-solver!" and
# dropped the whole pip update job for this repository, so no dependency
# update could ever be proposed here.
#
# The darwin cap at `<5` was also based on a false premise: z3-solver shipped
# no macOS wheel for 5.x. It does. Every 5.x release from 5.0.0.0 onwards
# publishes macosx_13_0 wheels for both arm64 and x86_64. The 4.15.5.0
# through 4.16.0.0 releases are the ones that raised their floor to macOS
# 15, and pip excludes those on wheel tags for an older macOS anyway.
#
# One requirement in both files also keeps `pip check` satisfied: the
# installed distribution's own requirement and this manifest now state the
# same thing. The engine is verified against 5.3.1.0, the version this range
# resolves to.
z3-solver>=4.12
control>=0.10
cvxpy>=1.5
casadi>=3.6

# Test runner , CI runs `pytest` to execute the test suite. Without this the
# test job fails immediately with "pytest: command not found" before any test
# is collected.
pytest>=8.0
