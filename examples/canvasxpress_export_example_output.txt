RENDERING THE DEFINITIONS
==============================================================================
  A definition is consumed by the CanvasXpress JavaScript library, which is not
  a dependency of this package. To render one in a browser, load the library and
  point it at the file:

    <canvas id="cx" width="640" height="480"></canvas>
    <script src="https://www.canvasxpress.org/releases/canvasXpress.min.js"></script>
    <script>
      fetch('01-state-trajectory.json').then(r => r.json()).then(function (cx) {
        new CanvasXpress('cx', cx.y ? {y: cx.y, x: cx.x, z: cx.z} : cx.data,
                        Object.assign({}, cx.config || {}, {title: 'Axiomize run'}));
      });
    </script>

  No Python-side rendering is claimed or performed here, because none is needed:
  the deliverable is the chart definition, and it is valid JSON on disk.
